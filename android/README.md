# 場邊教練 Android（原生版）

- **下載**：https://github.com/yuhyahliu/table_tennis/releases/latest/download/tt-coach.apk
- 每次推送 `android/` 的變更，GitHub Actions 會跑單元測試、編譯 APK，並更新上面的下載連結。

## 在 Pixel 上安裝
1. 用 Chrome 打開上面的下載連結，下載 `tt-coach.apk`。
2. 點下載完成的通知 → 安裝。第一次會要求允許 Chrome「安裝不明應用程式」，允許即可。
3. 之後更新：重新下載、安裝，會直接覆蓋舊版，設定和校正都會保留。

## 0.11：修正「五下只重播幾下」
- 0.10 改了擊球時間的抓法後，「計數」和「評分」帶的時間不一致，有些揮拍有嗶聲、有計數，卻沒有被算進這一輪的評分，重播就少了那幾下。現在兩者用同一個時間，並新增單元測試守住。

## 0.10：擊球時機更準
- 「是不是一下揮拍」仍用平滑後的訊號判斷（抗抖動），但擊球那一刻改回原始手腕速度的最高點：平滑會把高峰往後推 1–3 張畫面，重播停格常停在收拍附近。
- 用選手資料標記的真實擊球時間驗證：平均誤差 29 → 16 毫秒（每秒 30 張與 15 張皆同）；新增單元測試守住這個精度。

## 0.9：不用斜站、每秒張數提高
- 取消「站斜 45 度」的要求：把手機當成球桌對面，照平常打球的方式站就好。模擬顯示從正面到斜 60 度，擊球時機誤差都約 0.05 秒；只有完全側身（>70°，拍子手被身體擋住）才提醒「身體轉回來一點」，最多等 5 秒不卡關。
- 影像輸入改 960×540、重播畫面隔一張存一張、記錄檔改在背景執行緒格式化：減少每張畫面的工作，提高每秒張數（上次實測約 15 張）。

## 0.8：用小孩的真實資料校正
- 用一次真實練習記錄（手機每秒約 15 張、小孩佔畫面 85% 高）重跑：0.6 版那一輪只算到 5 下，0.7 以後的引擎算到 24 下（每 1.5 秒一下，很規律）。
- 那一輪主要問題是「手臂打直」：擊球時手肘約 145–160°（選手約 100°），2D 畫面也一樣直，是真的動作問題，不是量錯。
- 專心練一項時，目標改成「比自己上一輪進步」（上一輪中位數的 6 成），不是一下就要做到選手水準，進步看得到；做到了再往下一步。
- 記錄檔每 200 行同步寫入一次，App 沒正常關閉也讀得到。

## 0.7：小孩的揮拍也抓得到
- 手腕位置先做平滑再算速度與路線：小孩站得遠、在畫面裡小，骨架點會抖，抖動曾讓真正的揮拍被判成「不像」。測試：骨架點抖 4–6 公分、每秒只有 15 張，選手的 10 下仍全部抓到（之前只抓到 0–6 下）。
- 比對「像不像」時允許較慢的揮拍（標準速度的 0.8–1.6 倍），各項評分也用小孩自己的節奏量；只比引拍到收拍那段，不含收拍後的回位。
- 速度門檻上限降為 1.8 m/s，且每次「引拍準備」都重算：大人先揮過、小孩接著揮，不會被大人的速度卡住。
- 除錯畫面多顯示這一下的節奏倍數（tempo）。

## 0.6：引拍開始、五下輪播診斷、轉身改用畫面量
- 開始／繼續：站好後像定格的影子一樣「引拍」停約 0.7 秒（拍子手旁的圓圈會填滿）就開始，不用舉手。教練點螢幕＝倒數 3、2、1。
- 5 下之後：五下輪流慢動作播放（疊影子），好的綠框「很棒！」，其他停在問題那一刻＋箭頭＋口訣；下方 1–5 可點選任一下，看夠了點「下一輪 ▶」，再引拍開始。
- 能量條只在教練除錯畫面顯示（速度不是目標）。
- 轉腰／轉胯改用畫面上肩膀、骨盆「變窄」的程度估計（前鏡頭量深度不準），其他項目不變。
- 每一下的原始數值（含重心左右位置）都寫進記錄檔，之後用小孩的資料來訂「重心轉移」的標準。

## 0.5：只算像樣的揮拍、舉手開始／暫停
- 揮得快只是「候選」；揮完約 0.4 秒，比對手腕的路線（左右＋上下、含方向）和標準動作像不像，像才「嗶」一聲計數。亂揮、走動、收拍回來都不算。長按畫面可看每一下「像 xx%」。
- 示範後出現 ✋「舉手開始」：手舉過頭（或點螢幕）→ 3、2、1 → 開始。練習中點一下＝暫停；走出畫面自動暫停、回來自動繼續；每輪重播後回到「舉手開始」。
- 開著「存骨架」時，每次空拍都存成 `下載/TTCoach/shadow_*.jsonl.gz`（骨架＋每一下為什麼算／不算），用來依小孩的真實動作調門檻。

## 0.4：空拍練習（正手＋反手）
- 首頁兩個橘色按鈕：「空拍練習 正手」「空拍練習 反手」。手機或平板放在前方 2–3 公尺、胸口高度，螢幕對著小孩（前鏡頭，像照鏡子）；也可以投到電視。
- 流程：全身入鏡 → 站的角度對了（正手：斜站像在球桌前；反手：面向手機）→ 看影子、輕輕揮兩下熱身 → 揮 5 下 → 慢動作重播 → 下一輪。
- **每一下都有反應**：揮到就「嗶」一聲，上方大字「3/5」和五個圓點馬上亮白，評分出來後圓點變綠／黃／紅、邊框閃色、星星、一個字的語音。可以連續揮，不用停。
- **揮拍能量條**（右側 ⚡）：跟自己平常的揮拍比，白線以上才算一下；門檻依小孩自己的速度自動調整，不用跟選手一樣快。
- **影子跟著你的動作走**：揮到哪、影子就在那個階段的標準姿勢；站著不動 3 秒，影子自己示範一次。
- **5 下後重播**（約 10 秒）：最棒的一下（綠框、半速、影子疊上、停在擊球點「這下很棒！」）→ 最需要加油的一下（紅框、半速、停在問題那一刻，大箭頭＋口訣；轉身類的是弧形箭頭）。點一下可跳過。
- 下一輪：有問題就「只想一件事」練 5 下，做到 4 下以上回到自由揮拍。
- **教練除錯**：長按畫面，顯示手腕速度、門檻、上一下為什麼沒算、身體角度、每秒張數。
- 標準正手：「Table Tennis Forehand Stroke Mediapipe Datasets」（LyuLyu, figshare, DOI 10.6084/m9.figshare.28881086, CC BY 4.0），34 位省隊選手 340 拍。
- 標準反手：TTMD6 桌球動作捕捉資料（figshare 31746358, CC BY 4.0）的反手攻球。
- 兩者都換算成使用者自己的身材。

## 0.2 有什麼
- 相機每秒 60 張（手機支援時），手機上即時骨架辨識（MediaPipe，GPU）。
- 四點校正 + 放大鏡 + 手機擺放建議；比賽／練習兩種模式。
- 每分結束的提示；第 3 分後鎖定「本局重點」，之後每分回報 ✓/✗ 與連續做到幾分；目標依選手自己的水準調整。
- 大按鈕計分（長按收回）、局間重點、語音（中文）。
- **資料收集**：每次使用都存下骨架資料（`下載/TTCoach/*.jsonl.gz`）和影片（`影片/TTCoach/*.mp4`），用來調整擊球偵測、大臂小臂、轉胯。

## 程式
| 檔案 | 內容 |
| --- | --- |
| `Engine.kt` | 教練邏輯（校正、量測、回合判斷、提示、局間重點），純 Kotlin，有單元測試 |
| `CoachActivity.kt` | 相機、骨架辨識、計分、語音、資料記錄 |
| `OverlayView.kt` | 畫球桌框、校正點、放大鏡、骨架 |
| `MainActivity.kt` | 設定畫面 |
| `SessionLog.kt` | 骨架資料寫檔 |
| `EngineTest.kt` | 用參考比賽影片的骨架資料驗證引擎 |
| `Shadow.kt` | 空拍模式：標準動作換算身材、揮拍偵測、星星評分、口訣 |
| `ShadowActivity.kt` / `ShadowView.kt` | 空拍模式的前鏡頭、計數、能量條、跟隨影子、慢動作重播 |
| `ShadowTest.kt` | 用 figshare 選手正手與 TTMD6 反手資料驗證揮拍偵測、評分、影子跟隨 |
