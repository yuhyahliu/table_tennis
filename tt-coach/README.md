# 場邊教練 v0.1

給教練看的桌球即時提示網頁 App。手機架在場邊，每一分打完顯示選手的重心、站位、步寬、離桌距離；局間整理兩三個重點。

- 所有影像都在手機上處理，不會上傳。
- 第一次開啟需要網路（下載辨識模型約 6–10 MB），之後可離線使用。

## 放上 GitHub Pages（約 5 分鐘）

1. 登入 GitHub → 右上角「+」→ **New repository**
   - Repository name：`tt-coach`（可自訂）
   - 選 **Public**（免費帳號的 Pages 只支援公開 repo）→ **Create repository**
2. 在新 repo 頁面點 **uploading an existing file**，把這個資料夾裡的所有檔案（含 `icons` 資料夾）拖進去 → **Commit changes**
3. **Settings** → 左側 **Pages** → Source 選 **Deploy from a branch** → Branch 選 `main`、資料夾 `/ (root)` → **Save**
4. 等 1–2 分鐘，網址會是 `https://你的帳號.github.io/tt-coach/`

更新版本時，重複步驟 2 上傳新的檔案即可（同名檔案會被覆蓋）。

## 測試順序

1. **Mac**：用 Chrome 或 Safari 打開網址 →「用影片測試」→ 選比賽影片 → 依序點四個點 → 開始。
   - Chrome 播不了 iPhone 的 .mov 時，改用 Safari。
2. **iPhone 14 / 16**：Safari 打開網址 → 分享 →「加入主畫面」，從主畫面開啟比較像 App。
3. **Pixel 9a**：Chrome 打開網址 → 右上選單 →「安裝應用程式」。

畫面上方會顯示每秒處理幾張（fps）。低於 8 會提示太慢，請在設定改「快速」辨識。

## 使用方式

- **模式**：比賽（預設靜音、手機放端線後方觀眾區、盡量放高）／練習（開語音、手機放持拍手側後方斜 45 度）。
- **校正**：依序點 ① 選手這側左桌角 ② 右桌角 ③ 右邊線與球網交點 ④ 左邊線與球網交點。點完可以拖動微調，下方會提示手機位置要怎麼調。腳架沒動的話，下次會沿用上次的校正。
- **計分**：左下「對手 +1」、右下「我方 +1」；**長按任一邊可收回上一分**。一局打完（11 分且領先 2 分）會自動跳出局間重點。
- **暫停時**：按「局間重點」看這局目前的兩三個重點。
- **紀錄**：每一分的數據與提示；可下載 JSON 檔。

## 目前做不到的

- 大臂、小臂、轉胯、還原：需要抓到擊球瞬間。以每秒 30 張從背後拍，擊球偵測只抓得到約三分之一，排在原生 App（每秒 60 張）。
- 追球、落點、發球長短、對手分析：需要原生 App 與高幀率。
- 等級：目前固定用中級的標準，自動判定要等擊球偵測完成。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 畫面與樣式 |
| `app.js` | 相機、MediaPipe 骨架辨識、校正、計分、語音 |
| `engine.js` | 教練邏輯：從四點校正算出相機位置、量重心/站位/步寬/離桌、判斷回合、產生提示與局間重點 |
| `sw.js`、`manifest.webmanifest`、`icons/` | 離線快取與「加入主畫面」 |
